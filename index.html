01 Experimental prototype, under development

Personal project

GAIN

Personal Intelligence System

An exploration of how fragmented personal information might become more useful when it can be searched and understood in one place.

Orchestrating the pieces of an AI system raises practical architecture questions, especially when models need to run on personal hardware.

The current implementation is a local AI assistant built with Python, Ollama, and SQLite. It supports local language-model interaction, explicit memory management, PDF discovery and document reading, and lexical search.

What I’m learning

Model choice and responsiveness are shaped by available hardware. Connecting more personal data sources and generating tailored recommendations are part of the broader vision, not features of the current prototype.

02 Academic team project

Team project

Patient data
analysis system

Java, SQLite, console application

Project cover image not supplied

A Java and SQLite console application designed to load and analyse laboratory datasets as an academic team project.

I helped coordinate the team, organise meetings and tasks, manage our Git environment and OneDrive files, and contribute to the initial data loading and analysis.

I also contributed code and helped shape the final direction by bringing teammates’ ideas together and proposing improvements.

Known limitations

CSV parsing, database schema consistency, and unit-aware analysis have known limitations. The application is an academic project; it is not clinically validated and should not be used to inform clinical decisions.
