GAIN Core technical overview

A concise description of the implemented Python terminal prototype in the GAIN repository’s main branch.

Scope

GAIN Core is experimental software, not a production service. This overview describes chat_v3_2.py and its local tools. GAIN Brain and other product concepts are outside this implementation.

Implemented flow

  1. Local model interaction. The terminal assistant sends prompts to the Ollama API at http://localhost:11434/api/chat using the local model named gain. Ollama can return a tool call; Python runs that local function and returns its result to the conversation.
  2. Explicit memory. The commands remember, memories, and forget <id> manage records in ~/GAIN/memory.db. Saved memory content is read into assistant context for later prompts.
  3. PDF discovery. file_tools.find_files(".pdf") lists PDF filenames in ~/Downloads.
  4. Page-specific reading. chat_v3_2.read_pdf uses pypdf to extract selected, one-based pages. Each call is limited to three pages and 9,000 characters.
  5. Lexical PDF search. pdf_search.search_pdf_content searches extractable PDF text and returns filenames, page numbers, excerpts, and scan-coverage information.

The assistant orchestrates these operations locally. PDF text is document data, not a source of instructions.

Boundaries

Search is lexical, not semantic, and only extractable PDF text is searchable. The Core does not implement OCR, persistent conversation history, or production authentication. Future personal-data connections and personalized recommendations remain ideas, not implemented Core features.
